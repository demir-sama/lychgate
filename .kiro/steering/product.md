## Problem
Links die. Docs, READMEs, course lists, and blogs get 404s, soft-404s, content drift, and hijacked domains with no guided fix.

## Who
OSS and docs maintainers, technical writers and bloggers, teachers and researchers with link lists.

## Promise
Find every dead link, see how it died, resurrect it in one click.

## Core flow
1. Enter a site URL, a public GitHub repo, or pasted Markdown/list.
2. Classify each link: Living, Tombstone, Ghost, Drifted, Zombie.
3. Inspect cause, evidence, confidence, and the Wayback snapshot closest before the citation date.
4. Resurrect: pick snapshot or suggested replacement, preview, accept.
5. Leave with patched Markdown or a unified diff, a PR description, a shareable report, and a README badge.

## Out of scope
Accounts, private repos, OAuth, automatic PR creation (a PR opens only when a person presses "Open a pull request" with their own token), Save-Page-Now, browser extension, WordPress, PDF/DOCX, crawling beyond sitemap/page + 300 links, non-English UI, payments/crypto.
